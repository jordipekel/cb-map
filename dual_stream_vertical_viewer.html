Let op (Twitch Beveiliging): Je opent dit bestand rechtstreeks van je schijf (file://). Twitch vereist dat een pagina via een webserver draait (zoals localhost).
Oplossing: Gebruik VS Code Live Server, of run python -m http.server 8000 in de map van dit bestand en open http://localhost:8000.
